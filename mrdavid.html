🚀 Mr David Quick Start Guide

Welcome to Mr David, your private, AI-powered desktop assistant!

This guide will show you how to install Mr David and connect him to OmniRoute—a free AI proxy server that gives Mr David unlimited access to advanced AI models without requiring any paid API keys.

🛠️ Step 1: Install Mr David

  1. Double-click the MrDavid_Setup.exe file.
  2. Follow the standard Windows installation prompts.
  3. Once installed, Mr David will automatically launch, and you will see the Command Center.

🌐 Step 2: The Free AI Engine (OmniRoute)

Mr David needs a "brain" to think. Instead of paying for API keys, we use OmniRoute to pool free models from the internet.

Good news: I have automated this for you! Every time you open Mr David, he will silently launch the OmniRoute engine in the background.

Important Requirement: For this automatic engine to work, you must have Node.js installed on your computer. If you don't, simply download and install the LTS version from nodejs.org.

🧠 Step 3: Connect Mr David to the Engine

Now that OmniRoute is running, let's tell Mr David where to find it.

  1. Open the Mr David Command Center window.
  2. Navigate to the Settings or Identity Profile tab.
  3. Look for the "Custom API Endpoint" field.
  4. Paste the following URL exactly as shown: 
    http://localhost:20128/v1
  5. Click Save Configuration.

🎉 You're Done!

Mr David is now fully operational and running on free AI models!

To talk to him: Simply say his wake word or use the desktop Orb to start a conversation. He will use the OmniRoute connection in the background to process your requests.
